# AI Startup Workshop

A landing page for a practical AI workshop aimed at business owners who want to stop experimenting and start using AI in real workflows.

## Deployment

**Vercel:** Import the repo at vercel.com/new — it will detect a static site and deploy automatically. No configuration needed.

**GitHub Pages:** Go to Settings → Pages → set source to the `main` branch, root folder. The site will be live at `https://<your-username>.github.io/<repo-name>/`.
